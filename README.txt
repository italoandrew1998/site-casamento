SITE DE CASAMENTO — PROTÓTIPO FINAL

Inclui:
- confirmação pelo convidado;
- registro manual para idosos e outros convidados;
- acompanhantes;
- lista de presentes;
- aviso quando um presente já foi escolhido;
- possibilidade de escolher novamente o mesmo presente;
- painel dos noivos com convidados e presentes escolhidos.

ATENÇÃO:
Esta versão usa localStorage e é para teste. Os dados não são compartilhados entre celulares.
Para colocar no ar de verdade, o próximo passo é conectar o projeto ao Supabase, proteger a Área dos noivos com login e publicar na Vercel.
